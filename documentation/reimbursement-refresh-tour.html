New mail in. Review-ready report out.

The reimbursement workflow is now a deterministic local pipeline. Email acquisition, evidence refresh, report rendering, and Sheet writes remain visible, separate permission boundaries.

Shipped on main · feature commit 71d4232 · closeout issue #24

What the operator can do now

Choose the smallest action that matches the job in front of you.

1

Email only

Update the private local archive without building a report or touching Sheets.

uv run pta-finance fetch-mail \
  --since YYYY-MM-DD
2

Report only

Validate the current private bundle and atomically regenerate the HTML offline.

uv run pta-finance \
  report-reimbursements
3

End to end

Preview first; then acquire mail, refresh stable evidence, and render in one local run.

uv run pta-finance \
  update-reimbursements \
  --fetch-since YYYY-MM-DD \
  --dry-run

uv run pta-finance \
  update-reimbursements \
  --fetch-since YYYY-MM-DD
Safety boundary: none of these commands sends email or writes a Google Sheet. Replacing the machine-owned Reimbursements tab remains a separate explicit map-receipts --write-tab Reimbursements action.
